# Prime Bites Restaurant Website

A simple red-and-white restaurant website demo for Prime Bites.

## Menu
The menu is intentionally limited to three sections:
- **Local Dishes:** selected Ghanaian favourites, including jollof rice with chicken, banku with grilled tilapia, fufu with light soup, ampesi with kontomire stew, kenkey with fish, banku with okro stew, red red, gari and beans, tuo zaafi with ayoyo soup, and kelewele.
- **Continental Dishes:** burgers, sandwich, pizza, spicy chicken with fries, French fries, grilled beef steak, grilled tilapia, and fish and chips.
- **Drinks & Fresh Juice:** matcha boba, fresh pineapple juice, mango juice, and strawberry lemonade.

Chinese and Asian dishes, wraps and quick bites, desserts, separate fruit listings, and extra categories have been removed.

## Run it
Open `index.html` in a modern browser. Food photographs load from Unsplash and therefore need an internet connection. If a photo fails to load, the menu card displays a dish-specific emoji and its name rather than an empty image area.

## Demo limitations
- Orders and order history are stored in the current browser using local storage. They do not sync across devices.
- Payment is a demonstration only; no real payment is collected.
- Replace sample contact information before publishing for real customers.
